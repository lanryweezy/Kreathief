🛡️ Sentinel: [MEDIUM] Replace weak PRNG Math.random() with crypto.randomUUID() for ID generation

🚨 Severity: MEDIUM
💡 Vulnerability: `Math.random()` was being used for generating unique identifiers (like guide IDs and brand kit IDs) in `store/slices/uiSlice.ts` and `services/brandMemory.ts`. `Math.random()` provides insufficient entropy and is predictable, which can lead to ID collisions or expose the internal state of the PRNG.
🎯 Impact: Using weak pseudo-random number generators for unique identification violates secure coding standards, triggers SAST tool warnings, and introduces the risk of ID collisions across sessions or predictable entity creation.
🔧 Fix: Replaced all identified `Math.random()` ID generation logic with the cryptographically secure `crypto.randomUUID()`, using `.substring(0, 8)` to maintain the short length of the generated IDs.
✅ Verification: Ran unit tests (`pnpm test`) and linting (`pnpm exec eslint store/slices/uiSlice.ts services/brandMemory.ts`) to ensure the changes did not break existing functionality and the codebase remains stable.
