⚡ Bolt: Replace separate Zustand subscriptions with useShallow

💡 What: Refactored `components/panels/DrawPanel.tsx` to combine 8 independent `useStore` property accesses into a single object selector wrapped in `useShallow`.
🎯 Why: Multiple independent `useStore` hooks trigger separate store subscriptions. Consolidating them with `useShallow` minimizes listener overhead and reduces re-evaluations during rapid state updates, conforming strictly to codebase architectural guidelines.
📊 Impact: Reduces independent store listener evaluations from 8 to 1 for this panel, making rendering more efficient during intensive drawing interactions.
🔬 Measurement: Can be verified by using React Profiler or tracing store listener counts during DrawPanel interactions.
