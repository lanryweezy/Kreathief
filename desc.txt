### 💡 What
Extracted redundant `if ('vibrate' in navigator)` checks and inconsistent `try/catch` logic across seven different methods in `utils/haptics.ts` into a single, shared private helper function `vibrate(pattern)`. Also added robust unit tests for the utility.

### 🎯 Why
The file contained identical boilerplate checking for browser capability in every single exported function. Some functions used `try/catch` to suppress potential errors, while others did not. This consolidation provides a single source of truth, guarantees consistent error suppression, and makes the utility safer for SSR/Node environments by checking `typeof navigator !== 'undefined'`.

### 🔓 Behavior
The observable behavior remains identical. The utility still safely ignores calls if the API is missing, and triggers identical vibration patterns when supported.
